# Changelog

All notable changes to this project will be documented in this file.

## [0.1.0] - 2026-09-11

### Added
- Initial release of kilawatt-js
- Official Node.js/TypeScript client for Kilawatt Cloud GPU compute API
- Full API integration for GPU provisioning and management
- TypeScript support with exported type definitions
- Support for inference and fine-tuning workloads
